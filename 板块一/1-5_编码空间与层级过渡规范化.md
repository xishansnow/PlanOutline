# 1-5 GeoSOT 编码空间与层级过渡的规范化及标准修订建议

所属：板块一 · 轴对齐剖分网格的适用性评估与演进 ｜ 返回总览：[PlanOutline.md](../PlanOutline.md)

## 1. 定位

GeoSOT 为实现度、分、秒的整数层级，把地球扩展到 512°×512°，并把 1° 扩展为 64′、1′ 扩展为 64″ 后再做四叉剖分 [^1]。这一设计带来了与经纬度格网对齐的优势，也带来了三类代价：编码空间中大量无效编码；层级过渡处同层网格尺寸不一致、出现部分有效网格；四进制字符码、二进制整数与混合进制字符码多种编码形式并存。

本文在不改变核心编码的前提下，系统规范上述问题：给出有效性语义与判定算法，规范层级过渡处的网格，确立二进制整数为统一主码，并汇总板块一各篇的成果形成标准修订建议。

## 2. 研究问题

1. 如何为每个编码给出明确的有效性分类与有效几何，并以位运算常数时间判定？
2. 层级过渡处尺寸不一致的网格如何在误差分析、面积加权与规范形式中统一处理？
3. 统一主码采用何种二进制布局，才能同时容纳 32 个层级、层级信息与三维、时间扩展？
4. 如何把板块一的成果组织为一份向后兼容的标准修订建议？

关键问题：任何修订都须向后兼容既有数据与终端。

## 3. 研究内容

### 3.1 编码有效性语义

按剖分规则，每个编码属于三类之一：

| 类别 | 含义 | 处理 |
| --- | --- | --- |
| 有效 | 网格完全位于经度 ±180°、纬度 ±90°，且分、秒部分小于 60 | 正常使用 |
| 部分有效 | 网格跨越有效域边界或 60′、60″ 处 | 以有效几何 $g(c)=c\cap V$ 参与计算，面积按有效部分计 |
| 无效 | 网格完全位于有效域之外 | 不得出现在数据中；可作为保留空间（见 1-4） |

依据剖分提出者论文 [^1] 的定义推算（第 0 层为中心与原点重合的 512°×512° 网格，1° 扩展为 64′，1′ 扩展为 64″；已逐层枚举验证，与 GB/T 40087-2021 文本的一致性仍待核对）：分级扩展中，1° 扩展为 64′ 后，第 10 层网格为 32′，第二个子网格只有 28′ 有效；第 11 层为 16′，最后一个子网格只有 12′ 有效；第 12 层为 8′，最后一个只有 4′ 有效；从第 13 层（4′）起，60′ 可被整除，网格要么完全有效、要么完全无效，不再出现部分有效网格。秒级扩展的第 16 至 18 层同理。度级层级上，第 0 至 7 层也存在部分有效网格（90° 与 180° 不是这些层级单元边长的整数倍），第 8、9 层不存在。

本文给出每一层的有效性判定位运算，以及部分有效网格有效几何的闭式表达，作为 2-1 规范形式、2-2 邻接算法、1-2 扩展单元裁剪与 1-3 面积计算的共同基础。

### 3.2 层级过渡处的规范

- 名义尺寸与实际尺寸：为每个网格同时给出名义尺寸（按剖分规则）与实际尺寸（有效部分），文档与接口中明确区分。
- 误差分析：以实际尺寸计算定位精度与量化误差，给出各层级精度声明的上下界，与板块三“编码长度即精度声明”衔接。
- 规范形式：2-1 中“子网格全部存在则合并为父网格”的规则，对部分有效网格应按“有效子网格全部存在”判断，避免因无效子网格缺失而无法合并。

### 3.3 统一主码与派生表达

二维 GeoSOT 每层 2 位，32 层恰好占满 64 位，没有余量表示层级本身。候选布局：

| 布局 | 构成 | 优点 | 缺点 |
| --- | --- | --- | --- |
| （层级，编码）对 | 64 位编码 + 单独的层级字段 | 不损失层级，前缀运算直接 | 占用超过 64 位，或需两列存储 |
| 哨兵位 | 在编码末尾加一位标记层级（S2 单元编号采用这种方式） | 单个整数即可表示，排序与前缀运算自然 | 32 层时需 65 位，只能用 128 位整数或限制层级 |
| 128 位统一码 | 三维每层 3 位共 96 位，加层级与类型字段 | 二维、三维、时间统一 | 存储开销增大 |

研究目标是确定一种二进制整数作为统一主码，四进制字符码与混合进制字符码作为其派生表达，给出彼此之间无损、双向、可穷举验证的转换规则，并与北斗网格位置码、北斗剖分时间码的层级对应关系一并梳理，回应“维度不协调”与“编码形式多样”两项缺陷。

### 3.4 标准修订建议

汇总板块一各篇成果，按“规范性条款”与“资料性附录”两类组织：

| 建议项 | 来源 | 性质 |
| --- | --- | --- |
| 编码有效性分类与判定规则 | 本文 3.1 | 规范性 |
| 部分有效网格的有效几何与名义、实际尺寸 | 本文 3.2 | 规范性 |
| 二进制统一主码及与字符码的转换 | 本文 3.3 | 规范性 |
| 扩展单元的存储键与附加位 | 1-2 | 资料性 |
| 等面积派生视图及其与标准网格的对应 | 1-3 | 资料性 |
| 极冠剖分与衔接规则 | 1-4 | 规范性或资料性，视兼容性论证结果而定 |
| 独立存储排序键 | 2-5、2-6 | 资料性 |

每一项都附兼容性分析：既有数据是否需要迁移、既有终端是否需要升级，以及一致性测试用例。与 OGC 的对应关系及 GeoSOT 注册为 DGGRS 的定义草案见 1-6 [^2]。存储排序的评估已并入 2-5、2-6（见总览 2.2.6），本文不再展开。

## 4. 实验设计

| 项目 | 内容 |
| --- | --- |
| 有效性判定 | 在全部 32 层上穷举或分层抽样，与几何判定逐一比对 |
| 编码转换 | 各编码形式之间往返转换的穷举正确性测试与吞吐 |
| 规范形式 | 含部分有效网格的集合在合并、去重后与几何真值一致 |
| 兼容性 | 以既有 GeoSOT 数据集与软件接口回归测试 |

## 5. 预期成果

1. 编码有效性语义与常数时间判定算法。
2. 层级过渡处网格的规范与精度声明。
3. 统一主码布局与派生表达的转换规则。
4. 一份汇总板块一成果、附兼容性分析与一致性测试的标准修订建议稿。
5. 期刊论文一篇，建议投《测绘学报》或 IJGI。

## 7. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 修订建议被认为破坏兼容 | 所有建议均以附加层或派生表达实现，并附逐项兼容性分析 |
| 统一主码的选择争议大 | 给出多种布局的定量对比，由应用场景决定，并保证相互无损转换 |
| 标准修订周期长 | 先以团体标准或技术报告形式发布，再推动国家标准修订 |
