# 1-2 层级轴对齐网格中有范围对象的表达：扩展单元与覆盖优化

所属：板块一 · 轴对齐剖分网格的适用性评估与演进 ｜ 返回总览：[PlanOutline.md](../PlanOutline.md)

## 1. 定位

层级网格中，一个很小的对象只要恰好跨越某个粗层级网格的边界，其最小包围网格就会骤然变大，最坏情况下退化到很粗的层级。工程上常见的应对是退而用中心点编码，但这丢失了对象的范围，查询时只能扩大搜索窗口。本文为每个网格定义向外扩展的“扩展单元”，使任意对象都能以与其尺寸相称的层级表达，且扩展信息以附加位承载，不改变底层网格的标准编码。

边界问题是所有层级网格的共性，与是否轴对齐无关（1-1 的 2.3 节），XZ 序与松散四叉树在 Z 序网格上已有应用 [^1][^2]。本文的扩展单元以邻接关系定义，不依赖某一个具体网格，方法对 Geohash、Open Location Code 等层级网格同样适用；以 GeoSOT 为实现主线（不改变 GB/T 40087-2021 的标准编码，并处理其不规则层级、有效域等特殊情形），另选至多两个网格验证通用性。评价指标为 1-1 的指标 8（覆盖成本曲线），其 $K=1$ 特例是本文的基线。

本文的改进空间由 1-1 的边界问题解析模型给出上界；成果服务于 2-1 的编码代数与 7-1 的统一数据模型。

## 2. 研究问题

1. 如何定义扩展单元，使包围单元的面积与对象外包矩形最大边长的平方之比有确定的上界？细长对象（外包矩形的长宽比很大）如何处理？
2. 扩展单元相互重叠，如何保持对象表达的唯一性（规范形式），以及与 2-1 集合运算的封闭性？
3. 在条目数预算或查询代价模型下，如何在标准单元、扩展单元及其组合之间选择最优覆盖？
4. 在 GeoSOT 尺寸不规则的层级过渡处、180° 经线与两极附近，扩展规则如何保持一致？

关键问题：扩展单元引入重叠后，规范形式与集合运算如何保持唯一与封闭。

## 3. 研究内容

### 3.1 扩展单元的定义

借鉴 XZ 序 [^1] 的单向扩展思想：第 $l$ 层网格 $c$ 的扩展单元定义为 $c$ 与其东邻、北邻、东北邻网格的并：

$$E(c)=c\cup N_{\mathrm{E}}(c)\cup N_{\mathrm{N}}(c)\cup N_{\mathrm{NE}}(c)$$

以邻接网格的并而非几何放大来定义，有三个好处：扩展单元始终可以精确写成标准网格的集合；层级过渡处尺寸不一致（如 32′ 与 28′）时自动按真实网格计算；跨 180° 经线时东邻自然回绕，复用 2-2 的邻接算法。

对象分配规则：取对象外包矩形的西南角所在网格作为锚点，选择满足“外包矩形完整落入 $E(c)$”的最细层级 $l$。当网格尺寸规则时，只要对象边长不超过 $d_l$ 即可落入，由此得到：

- 唯一性：锚点与层级都由对象几何确定性给出，同一对象只有一种表达。
- 面积上界：所选层级满足 $d_l<2s$（$s$ 为对象外包矩形最大边长），扩展单元面积不超过 $4d_l^2<16s^2$，与对象位置无关；标准最小包围网格则没有这样的上界。
- 上界的口径：该上界是相对 $s^2$ 的，不是相对外包矩形面积 $wh$ 的。设 $w\ge h$、长宽比 $\rho=w/h$，则扩展单元面积与外包矩形面积之比小于 $16\rho$；对细长对象（如长 1 km、宽 5 m 的道路段，$\rho=200$）这个比值没有实用的上界。细长对象的处理见 3.2：沿长轴切分为若干段，每段各取一个扩展单元。

一般化：上述定义只用到邻接关系。设层级网格每层每个轴的细分比为 $r$（四叉网格 $r=2$），则所选层级的更细一层必不满足落入条件，即 $d_l/r<s$，扩展单元面积不超过 $4d_l^2<4r^2s^2$；$r=2$ 时即 $16s^2$。该推导为一般化的初步结论（须在正式写作时补全证明）：对细分比为 2 的纯二进制网格（WorldCRS84Quad、GNOSIS 的常规行）常数不变；Geohash 逐层交替二分，两个轴的单元尺寸在相邻层级间交替，须分轴推导；Open Location Code 相邻有效层级的细化比为 400，即每轴 $r=20$，上界常数大幅变差，说明层级稀疏的网格更依赖扩展单元之外的覆盖优化（1-1 的指标 8）。

对比方案：松散四叉树式的对称扩展 [^4]（以网格中心为基准向四周放大 $k$ 倍）。$k$ 越大，对象可分配到越细的层级，但单元重叠越多、查询候选越多；本文以实验给出 $k$ 的权衡曲线，并与单向扩展比较。

### 3.2 覆盖优化

3.1 的扩展单元用一个条目换来 $16s^2$ 的面积上界，但对细长对象无效，也不一定是代价最低的表达。本节把对象表达看作一个覆盖选择问题，扩展单元只是其中一种构件。

**问题形式化。** 对象 $O$ 的覆盖方案 $C$ 是若干构件的集合，构件可以是标准单元（可混合层级）或扩展单元，其并须包含 $O$。两个基本量：条目数 $\lvert C\rvert$（每个构件一个索引条目，决定存储、去重与范围扫描开销）；冗余面积比 $\eta(C)=A(\cup C)/A(O)$（决定查询的候选冗余）。1-1 的指标 8（覆盖成本曲线）即 $\eta^*(K)=\min_{\lvert C\rvert\le K}\eta(C)$，其对偶形式是给定 $\eta$ 上限时最小的 $K$。总代价还可写成 $J(C)=\alpha\lvert C\rvert+\beta\,(\eta(C)-1)$，权重 $\alpha,\beta$ 由负载决定，对应 1-1 的应用画像中“对象类型”与“索引与存储”两个维度。

**候选构件与初步性质**（以下均为推导，须在正式写作时补全证明）：

| 方案 | 条目数 | 冗余面积比 | 说明 |
| --- | --- | --- | --- |
| 标准最小包围单元 | 1 | 无界 | 3.1 的基线，对象跨粗层级边界时骤然变大 |
| 尺寸相称层级的 2×2 标准单元覆盖 | 至多 4 | 小于 $16\rho$（与扩展单元同阶） | 取 $d_l\ge s$ 的最粗层级，对象至多覆盖 2×2 个单元；有重复条目，须去重 |
| 单个扩展单元 $E(c)$ | 1 | 小于 $16\rho$（$\rho$ 为长宽比） | 3.1；紧凑对象 $\rho\approx1$ |
| 细长对象沿长轴切分，每段取一个 $E(c)$ | $m=\lceil w/h\rceil$ | 小于 32 | 设 $w\ge h$，每段边长不超过 $h$，每段面积小于 $16h^2$，合计小于 $16(w/h+1)h^2\le32wh$；以条目数换面积；设 $h$ 不小于最细层级的单元尺寸，否则退化为最细层级处理 |
| 混合层级的标准单元覆盖 | 预算 $K$ | $K\to\infty$ 时趋于 1 | 四叉树式递归细分，$\eta^*(K)$ 单调不增 |
| 带扩展模式位的扩展单元（待研究候选） | 1 | 介于上述之间 | 用 2 位标记扩展方向：仅 $c$、$c\cup N_{\mathrm E}$、$c\cup N_{\mathrm N}$、$c\cup N_{\mathrm E}\cup N_{\mathrm N}\cup N_{\mathrm{NE}}$，面积为 $d^2$、$2d^2$、$2d^2$、$4d^2$；以多一位附加位换更紧的覆盖 |

**算法。** 从最小包围单元出发做贪心细分：每次选择“冗余面积减少量 / 条目增加量”最大的细分，直到达到预算 $K$ 或 $\eta$ 阈值；扩展单元与切分作为额外的候选动作加入。规模为单个对象的小问题，可用动态规划验证贪心解的近似程度。并列时取更粗层级、再按编码字典序，保证解确定，便于与 3.5 的规范形式衔接。

**与查询、存储的关系。** 条目数直接影响索引大小、去重与范围扫描数，冗余面积比直接影响候选集大小。因此同一对象集上不同表达方式的优劣，取决于查询类型（点查询、窗口查询、空间连接）与对象的尺寸、长宽比分布，不存在对所有画像最优的表达。本节的输出不是一个固定方案，而是按应用画像给出推荐的表达方式，以及 $\eta^*(K)$ 曲线随网格细分比的变化：细分比 $r$ 越大（如 Open Location Code 每轴 $r=20$），层级越稀疏，混合层级覆盖相对扩展单元的价值越大（推断，待实验验证）。

### 3.3 编码与存储

- 扩展标志：在标准编码之外附加 1 位扩展标志，构成存储键（标准编码，扩展标志）。标准编码本身不变，不识别扩展位的系统仍可按标准编码读取，只是把对象视作锚点网格。
- 三维与四维：GeoSOT-3D 中扩展单元由 8 个网格构成，时间维可按时间片同理扩展；附加位数量随维度增加，需评估存储开销。

### 3.4 查询处理

窗口查询 $Q$ 在第 $l$ 层的候选锚点，是与 $Q$ 向西、向南各外扩一个网格后的区域相交的网格。由此把扩展单元的查询转化为标准网格的前缀范围查询，可直接利用现有索引。查询结果经精确几何校验，保证不漏不错。

### 3.5 规范形式与集合运算

扩展单元只作为索引与表达层的单元，不进入 2-1 的集合代数：参与相交、包含等运算前，把 $E(c)$ 展开为至多 4 个标准网格（三维至多 8 个），再按 2-1 的规范形式（合并、去重、层级归一）处理。这样集合运算始终在不重叠的标准网格上进行，封闭性与唯一性由 2-1 保证；本文需证明“展开 → 运算 → 结果”与直接几何运算一致。

### 3.6 特殊位置的规则

| 位置 | 问题 | 处理 |
| --- | --- | --- |
| 层级过渡处（GeoSOT 特有，见 [^3]） | 相邻网格尺寸不同，面积上界的常数改变 | 按实际网格尺寸重新推导上界，单独报告 |
| 180° 经线 | 东邻跨越经线 | 使用 2-2 的跨经线邻接 |
| 两极附近 | 北邻不存在或退化 | 扩展失败时回退到父层级，或采用 1-4 的极区规则 |
| 有效域边界（GeoSOT 特有） | 邻居位于无效编码区域 | 以 1-5 的有效性判定裁剪 |

| 几何指标 | 包围单元面积 / 对象外包矩形面积（均值、95 分位、最大值），并按长宽比分层统计，同时报告相对 $s^2$ 的比值；分配层级与“理想层级”之差；不同细分比下面积上界常数的实测与推导值对照 |

| 存储指标 | 索引大小、附加位开销 |
| 正确性 | 与几何真值对比的查询结果一致性；集合运算展开前后一致性测试 |

## 5. 预期成果

1. 带面积上界证明的扩展单元定义与分配算法，包括对细长对象的处理。
2. 覆盖优化问题的形式化、代价模型与算法，以及覆盖成本曲线 $\eta^*(K)$ 随网格细分比的变化；按应用画像给出推荐的对象表达方式。
3. 扩展单元与标准编码共存的存储键设计与查询改写方法。
4. 与 2-1 集合代数衔接的展开规则及正确性证明。
5. 期刊论文一篇，建议投 IJGIS 或 GeoInformatica；可作为 1-5 标准修订建议的一项内容。

## 7. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 审稿人认为只是 XZ 序的移植 | 突出在不规则层级、跨经线、极区与有效域处理上的一般化，以及与标准编码共存的设计，并以覆盖成本曲线给出定量比较；以覆盖优化（3.2）为论文主线，扩展单元只是其中一种构件，真正的增量在于代价模型、对细长对象的处理、扩展模式位与按画像的推荐 |
| 多层级前缀范围扫描开销过大（3.4 尚未量化） | 推导每层范围数上界，合并相邻层级的范围，必要时限制候选层级集合；在实验中单独报告范围数与延迟 |
| 附加位与现有系统不兼容 | 附加位放在标准编码之外的存储键中，不修改编码本身 |
| 层级过渡处的上界变差 | 如实报告分段上界，并在 1-5 规范化后重新评估 |
