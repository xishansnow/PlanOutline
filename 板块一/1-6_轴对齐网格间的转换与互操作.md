# 1-6 轴对齐剖分网格间的转换与互操作：层级对应、守恒重映射与 DGGRS 注册

所属：板块一 · 轴对齐剖分网格的适用性评估与演进 ｜ 返回总览：[PlanOutline.md](../PlanOutline.md)

## 1. 定位

1-1 的结论是没有最好的 DGGS，只有最适用的 DGGS。这意味着实际系统中多种轴对齐网格会长期并存：国内有 GeoSOT 与北斗网格位置码，国际上有 Geohash、Web 墨卡托瓦片、Open Location Code [^5] 与 GNOSIS Global Grid。数据在这些网格之间流转时，常见做法是重新栅格化或逐点重新编码，既慢又有误差，物理量也不守恒。本文研究轴对齐网格之间的转换：层级如何对应，单元之间的包含与交叠如何精确计算，物理量如何守恒，以及如何按 OGC API – DGGS 的格式描述一个轴对齐网格，使其成为可注册、可互操作的 DGGRS [^1]。

狭义轴对齐网格的单元边界都落在经线与纬线上（见 1-1 的 2.1），两个单元的交叠就是经度区间与纬度区间各自相交的乘积，面积有闭式解，不需要多边形裁剪。这一性质是本文方法的基础，也是它区别于一般 DGGS 间转换的地方。

本文处理网格与网格之间的关系；单一网格内的集合运算与邻接计算分别由 2-1、2-2 负责，二者不重叠。成果服务于 1-5 的标准修订建议（GeoSOT 注册为 DGGRS 的依据）、7-1 的统一数据模型与板块六的守恒重映射。

## 2. 研究问题

1. 狭义轴对齐网格之间，单元的包含与交叠面积能否闭式精确计算？对 Web 墨卡托瓦片这类纬线间距非线性的网格，是否同样成立？
2. 两个网格之间的层级如何对应？哪些层级对之间是精确的包含关系，哪些只是近似，近似的程度多大？
3. 在转换中如何保证物理量守恒，一阶与二阶守恒的代价各是多少？
4. 如何按 OGC 的 DGGRS 定义描述 GeoSOT 这类具有扩展根区域、度分秒层级的网格？哪些参数无法直接表达？

关键问题：不依赖多边形裁剪，如何精确且守恒地在不同轴对齐网格之间转换。

## 3. 研究内容

### 3.1 转换的分类

| 类别 | 单元关系 | 处理 |
| --- | --- | --- |
| 精确嵌套 | 源单元恰为若干目标单元之并，或反之 | 直接展开或合并，无误差 |
| 部分交叠 | 源单元与若干目标单元部分重叠 | 按闭式交叠面积加权 |
| 经坐标变换 | 网格定义在不同的 $T$ 下（如 Web 墨卡托与经纬度） | 先把纬线位置变换到同一纬度参数，再按区间交叠处理 |

### 3.2 闭式交叠

狭义网格的单元为 $[\lambda_0,\lambda_1]\times[\varphi_0,\varphi_1]$。球面上两个单元的交叠面积为 $R^2\,\lvert\Delta\lambda_\cap\rvert\,\lvert\Delta(\sin\varphi)_\cap\rvert$，椭球上以等积纬度代入；该公式即 1-1 的 4.1 节面积公式，也是 1-3 闭式交叠的推广。对 Web 墨卡托瓦片 [^4]，纬线位置由瓦片行号经墨卡托反变换得到，同样得到区间端点，再按上式计算。跨 180° 经线时，经度区间按 2-2 的方式回绕处理。

### 3.3 层级对应表

对每一对网格，按 1-1 的指标 5（配对尺寸误差）和包含关系，枚举出：精确包含的层级对、近似对应的最优层级对及其尺寸比。对应表需逐对生成并以穷举验证，不预设某一对网格在哪些层级上重合。与经纬度栅格的对齐度（1-1 的指标 9）可作为特例：把栅格像元视为一个以分辨率为边长的网格。

### 3.4 守恒重映射

- 一阶守恒：目标单元的值为源单元值按交叠面积占源单元面积比例的加权和，保证总量守恒 [^3]。
- 二阶守恒：在一阶基础上加入源单元内的梯度项，提高光滑场的精度，代价是需要梯度估计。
- 与 1-3 的衔接：派生视图与标准网格之间的映射是本文的特例。

### 3.5 互操作接口与 DGGRS 注册

OGC API – DGGS 用一份 DGGRS 定义描述一个网格，字段包括坐标参考系、基础多面体、细化比、细化策略、约束（如 `cellAxisAligned`）、单元类型、椭球与朝向，以及单元标识方案和子单元顺序 [^2]。GNOSIS Global Grid 的定义可作为轴对齐网格的范例。对 GeoSOT 的描述存在几处需要研究的问题，以下均为推断，须与 GB/T 40087-2021 和 OGC 文本逐条核对：

| 问题 | 说明 |
| --- | --- |
| 细化比 | OGC 的细化比为单个整数；GeoSOT 在度、分、秒的层级过渡处按名义尺寸四分，但有效单元面积之比并非 4，细化比应取名义值还是有效值，需要确定 |
| 根区域与有效域 | 扩展根区域为 512°×512°，大量编码无效，需在定义中说明有效域（见 1-5） |
| 单元标识 | GeoSOT 的字符码、二进制整数与 OGC 的 `textZIRS`、`uint64ZIRS` 的对应关系 |
| 子单元顺序 | OGC 要求确定的子单元顺序，Z 序是否直接可用 |

在此基础上提供转换服务：按 OGC API – DGGS 的单元查询接口返回另一网格下的对应单元集合与权重，并附一致性测试用例。

## 4. 实验设计

| 项目 | 内容 |
| --- | --- |
| 网格对 | 从 1-1 的全套 7 个网格中选取典型的 5 至 6 对，覆盖精确嵌套、部分交叠与经坐标变换三类 |
| 正确性 | 闭式交叠与高精度数值积分对比；往返转换后的误差；层级对应表的穷举验证 |
| 守恒检验 | 在 ERA5 全球场上做网格间重映射，统计总量与区域均值的守恒误差，比较一阶与二阶 |
| 效率 | 与多边形裁剪、逐点重编码的基线比较吞吐与内存 |
| 互操作 | 生成 GeoSOT 的 DGGRS 定义，通过 OGC API – DGGS 参考实现的解析与单元查询测试 |
| 数据 | ERA5 再分析场；OSM 建筑轮廓；出租车或共享单车轨迹 |

## 5. 预期成果

1. 狭义轴对齐网格间的闭式交叠计算方法及其对 Web 墨卡托瓦片的扩展。
2. 各网格对的层级对应表，含精确包含与近似对应的定量描述。
3. 一阶与二阶守恒重映射方法及实验比较。
4. GeoSOT 的 DGGRS 定义草案，以及无法直接表达之处的清单，作为 1-5 标准修订建议和 OGC 对话的依据。
5. 开源的网格间转换库与一致性测试集。
6. 期刊论文一篇，建议投 IJGIS 或 International Journal of Digital Earth。

## 7. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 与 2-1、2-2、1-3 的工作重叠 | 本文只处理网格之间的关系，明确不涉及单一网格内的集合运算与邻接；与 1-3 共用闭式交叠，作为一般化而非重复 |
| GeoSOT 无法完整表达为 OGC 的 DGGRS 定义 | 如实列出无法表达之处，作为对 OGC 与标准修订的反馈，不强行改写 GeoSOT |
| 各网格的权威定义不齐，层级对应表出错 | 北斗网格位置码、GB/T 13989 分幅等按标准原文核对后再纳入；对应表以穷举测试验证 |
| 贡献被认为偏工程 | 突出闭式交叠与守恒的理论分析，以及层级对应的定量刻画 |
