# 1-4 经纬度轴对齐网格的极区剖分与全球衔接

所属：板块一 · 轴对齐剖分网格的适用性评估与演进 ｜ 返回总览：[PlanOutline.md](../PlanOutline.md)

## 1. 定位

经线在极点汇聚，经纬度剖分的近极网格退化为极窄的条带，一行网格共享极点，邻接关系复杂；北斗网格位置码的常规剖分只覆盖南北纬 88° 以内。极区虽然面积小，却是全球连续计算绕不开的地方：全球剖分图（2-4）、地球系统模式（板块六）、海冰与极地观测都需要在极区给出良好定义的网格与邻接。本文设计极冠剖分方案，定义极冠与常规区之间的邻接与层级衔接规则，并保持与 GeoSOT 编码及北斗网格位置码极区处理的兼容。

极区奇异是所有狭义轴对齐网格的共性（1-1 的 2.3 节）：GNOSIS 以变宽行使每极仅 4 个单元，北斗网格位置码在 88° 处分界，都是同一问题的不同解，可作为对照。本文的极冠方案与衔接规则以经纬度边界为前提，不依赖具体编码；以 GeoSOT 为实现主线（保持编码兼容），并与 GNOSIS、北斗网格位置码做对照分析。评价指标为 1-1 的指标 3（近极最小边长）及指标 1、4。

## 2. 研究问题

1. 极冠内采用什么剖分，使网格面积与形状接近常规区，且层级关系仍为四叉嵌套？
2. 极冠单元如何编码，既不与现有标准编码冲突，又能被现有系统识别或安全忽略？
3. 极冠与常规区交界处、跨极点处的邻接与层级衔接如何定义，使 2-2 的邻接计算在全球统一？

关键问题：在保持编码兼容的前提下，使极区邻接计算与常规区统一。

## 3. 研究内容

### 3.1 候选剖分方案

| 方案 | 思路 | 优点 | 缺点 |
| --- | --- | --- | --- |
| A 方位等积极冠 | 纬度 $\varphi_c$ 以上的极冠以极方位兰伯特等积投影映射到平面，在平面上做正方形四叉剖分 | 面积均衡、形状好，类似 EASE-Grid 2.0 的极区网格 \[1\] | 极冠单元与常规区网格边界不重合，需另编码 |
| B 经向合并 | 随纬度升高，沿经度把 $2^k$ 个网格合并为一个单元，极点附近退化为单个极冠单元 | 单元都是标准网格的并，与编码完全兼容，与 1-3 路线 B 一致 | 面积只能均衡到 $\sqrt2$ 倍以内，形状仍有梯形畸变 |
| C 旋转极网格 | 在极区叠加一套极点位于赤道的旋转经纬网格 | 完全复用 GeoSOT 剖分与编码算法 | 两套网格重叠，对应关系与数据归属复杂 |

方案 B 与 GNOSIS 的变宽行属同一思路（沿经度合并列，使极区行不沿经度分裂）；GNOSIS 任一层级仅 4 个单元触及每极（见 1-1 的 2.4 节），可作为方案 B 极点退化为单个极冠单元的对照。方案 A 与 EASE-Grid 2.0、HEALPix 的极冠做法属另一类（改变极区的坐标变换）。

研究以 A、B 为主线：B 以兼容性为先，作为默认方案；A 以几何质量为先，作为科学计算场景的可选方案；C 作为对照。

### 3.2 极冠编码（GeoSOT 实现）

以下编码设计针对 GeoSOT 的扩展编码空间；Geohash 等网格无无效编码空间，方案 B 的集合表示同样可用，方案 A 的编码须另行设计。

- 方案 B 无需新编码：极区单元直接以其所含标准网格的编码集合（或最西端编码加组宽）表示。
- 方案 A 需要新编码。候选做法之一是利用 GeoSOT 扩展编码空间中纬度绝对值超过 90° 的无效区域承载极冠编码：这些编码在现有标准中不对应任何有效位置，现有系统不会产生它们，因此不与既有数据冲突。这一做法是否与标准的有效性约束及北斗网格位置码的极区规则相容，需逐条对照 GB/T 40087-2021 与 GB/T 39409-2020 文本后才能确定，本文将其作为待论证的候选。
- 两种方案都需给出极冠单元与常规区网格之间的精确面积对应（交叠计算可借用 1-3 的闭式公式）。

### 3.3 邻接与层级衔接规则

| 位置 | 规则要点 |
| --- | --- |
| 极冠内部 | 方案 A 为平面正方形邻接；方案 B 为同纬度带内经向邻接，跨纬度带时一对多 |
| 极冠与常规区交界 $\varphi_c$ | 一对多邻接：一个极冠单元对应若干常规区网格，需给出确定的邻居列表与排序 |
| 跨极点 | 经度相差 180° 的单元经极点相邻；方案 B 中极点单元与最近一圈单元全部相邻 |
| 层级对应 | 极冠第 $l$ 层与常规区第 $l$ 层的单元尺寸应可比，衔接带的父子关系保持四叉 |

邻接函数统一返回邻居集合而非固定个数的邻居，使 2-2 的邻接算法与 2-4 的构图可以在全球一致地调用；需在有限层级上穷举测试并给出正确性证明。

### 3.4 分界纬度的选择

分界纬度 $\varphi_c$ 宜与北斗网格位置码的 88° 保持一致，以便两套编码在极区的处理口径相同；对其他网格，以其自身的极区规则（GNOSIS 的变宽行、WorldCRS84Quad 与 Geohash 不作处理）作为对照；同时以 1-1 的形状与面积指标评估 88° 之外的取值（如与 GeoSOT 某一层级网格边界对齐的纬度），作为敏感性分析。

## 4. 实验设计

| 项目 | 内容 |
| --- | --- |
| 验证网格 | GeoSOT 为主，与 GNOSIS、北斗网格位置码做对照分析；Geohash 作通用性验证 |
| 几何指标 | 极冠内单元面积与形状统计，与常规区及 HEALPix 极冠、EASE-Grid 2.0 极区网格对比 |
| 邻接正确性 | 与几何真值穷举对比，覆盖交界带、跨极点与 180° 经线 |
| 性能 | 邻居查询与父子查询的延迟，与常规区对比 |
| 下游任务 | 极区海冰密集度等极地格网产品的网格化与统计；含极区的全球剖分图（2-4）消息传递与预报误差；全球守恒重映射在极区的误差 |

## 5. 预期成果

1. 两种极冠剖分方案（兼容优先与几何优先）的定义、编码与层级规则。
2. 全球统一的邻接与层级衔接规则及其正确性证明。
3. 与北斗网格位置码极区处理的对照分析。
4. 期刊论文一篇，建议投 IJGIS 或《测绘学报》；规则可作为 1-5 标准修订建议的一项内容。

## 7. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 新编码与标准冲突 | 默认采用无需新编码的方案 B；方案 A 的编码方式经标准文本逐条核对后再提出 |
| 极区应用场景少，贡献被低估 | 以全球剖分图与地球系统模式的全球连续计算论证必要性，并结合极地观测产品验证 |
| 交界带规则复杂，实现易出错 | 以穷举测试与形式化证明保证正确性，测试集公开 |
