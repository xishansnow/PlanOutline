# 1-3 经纬度轴对齐网格的等面积派生视图与守恒重映射

所属：板块一 · 轴对齐剖分网格的适用性评估与演进 ｜ 返回总览：[PlanOutline.md](../PlanOutline.md)

## 1. 定位

GeoSOT 按经纬度剖分，同层网格面积随纬度按余弦收缩。这对全球统计、剖分图神经网络的节点均匀性、不确定性的跨层级聚合与地球系统模式的守恒重映射都构成障碍，也是与 HEALPix、ISEA 等等面积网格相比最常被质疑的一点。本文不改动 GeoSOT 本身，而是在其之上构建**等面积派生视图**，并给出派生单元与 GeoSOT 网格之间的精确对应关系，使需要等面积的计算可以在派生视图上进行，结果再无损地回到标准编码。

面积随纬度收缩是所有狭义轴对齐网格的共性（1-1 的 2.3 节）。等积纬度变换与聚合只依赖“单元边界为经线与纬线”这一性质，对 Geohash、WorldCRS84Quad 等同样成立；GNOSIS 以变宽行近似等面积，作为对照而非对象。本文以 GeoSOT 为实现主线（聚合宽度取 2 的幂以保持层级嵌套，并处理其不规则层级），另选至多两个狭义网格验证通用性。评价指标为 1-1 的指标 1 与 2（面积变异、长宽比与紧致度）。

成果服务于 2-4（剖分图节点均匀性）、板块三（概率分布的跨层级聚合）与板块六（守恒重映射、模式输出组织）。

## 2. 研究问题

1. 构造什么样的派生视图，能在面积均衡、形状、层级嵌套与编码兼容之间取得最好的平衡？
2. 派生单元与 GeoSOT 网格的对应关系能否精确计算，而不依赖多边形裁剪？
3. 派生视图边界与原网格边界不重合时，如何保证物理量守恒？

关键问题：派生视图与原网格的边界不重合时，对应关系与守恒如何保证。

## 3. 研究内容

本文比较两条互补的路线。

### 3.1 路线 A：等积纬度变换派生网格

以 $u=\sin\varphi$（球面）或 $u=\sin\beta$（椭球，$\beta$ 为等积纬度 [^1]）替代纬度，在 $(\lambda,u)$ 平面上做均匀四叉剖分。由于球面上经纬矩形的面积为

$$A=R^2\,\Delta\lambda\,(\sin\varphi_2-\sin\varphi_1)$$

$(\lambda,u)$ 平面上的等大矩形在球面上严格等面积，这就是兰伯特等积圆柱投影的网格化。

- 精确对应：任一狭义轴对齐网格的单元（以 GeoSOT 为例）$[\lambda_1,\lambda_2]\times[\varphi_1,\varphi_2]$ 与派生单元 $[\lambda'_1,\lambda'_2]\times[u'_1,u'_2]$ 的交叠面积为
  $$R^2\,\big|[\lambda_1,\lambda_2]\cap[\lambda'_1,\lambda'_2]\big|\cdot\big|[\sin\varphi_1,\sin\varphi_2]\cap[u'_1,u'_2]\big|$$
  即两段区间交集长度的乘积，有闭式解，无需多边形裁剪。由此直接得到一阶守恒重映射权重 [^2]，守恒误差只有浮点舍入。
- 层级嵌套：派生视图自身是规则四叉树，可赋予独立的派生编码，与 GeoSOT 编码通过上述权重表关联。
- 缺点：高纬度处派生单元在纬向被拉长，形状畸变比 GeoSOT 更严重。HEALPix 的做法是赤道带用等积圆柱、极冠另行处理 [^3]；本路线同样需要与 1-4 的极区方案组合。同类的等积投影网格还有 EASE-Grid 2.0 [^4]。

### 3.2 路线 B：面积均衡聚合网格组

在每个纬度带内，把沿经度相邻的若干 GeoSOT 网格合并为一组，合并个数 $n_b$ 随纬度增大，使各组面积大致相当。这一思路与数值天气预报中的缩减经纬度网格相近。

- 精确对应：每组都是标准网格的并，边界与 GeoSOT 完全重合，对应关系与守恒都是平凡的。
- 编码兼容：组可以用其最西端网格的编码加组宽表示，或直接表示为标准编码集合。
- 层级嵌套：取 $n_b$ 为 2 的幂，并使纬度带边界与父层级网格边界对齐，则父层级的组恰为子层级若干组的并，层级关系保持；代价是面积只能均衡到 $\sqrt2$ 倍以内。允许 $n_b$ 取任意整数可以更均衡，但会破坏与编码前缀的对齐。
- 通用性：路线 B 只要求网格边界为经线与纬线、层级细分比为 2 的幂；在纯二进制网格（Geohash、WorldCRS84Quad）上无需处理不规则层级，预期更易实现（推断），在 GeoSOT 上还须处理层级过渡处的不规则尺寸。

### 3.3 两条路线的比较维度

| 维度 | 路线 A（等积变换） | 路线 B（聚合网格组） |
| --- | --- | --- |
| 面积均衡 | 严格相等 | 2 的幂时在 $\sqrt2$ 倍以内 |
| 形状 | 高纬度拉长 | 高纬度较好，组宽随纬度变化 |
| 与原网格边界 | 不重合，需权重表 | 重合 |
| 守恒 | 闭式权重，舍入级误差 | 平凡成立 |
| 层级嵌套 | 自身嵌套，与 GeoSOT 经权重关联 | 2 的幂时与 GeoSOT 嵌套一致 |
| 编码 | 需独立派生编码 | 复用标准编码 |
| 极区 | 需与 1-4 组合 | 极冠可自然退化为单组 |

GNOSIS 的变宽行与路线 B 思路相近：二者都沿经度方向合并列，且 GNOSIS 的合并系数为 2 的幂（第 $k$ 个二进制纬度带合并 $2^{L-k}$ 列，已对 29 层逐层核对，见 1-1 的 2.4 节），只在纬度 45° 以上合并；路线 B 的合并从多低的纬度开始，是需要与之比较的设计参数。GNOSIS 的面积偏差约为 −25.8%/+66.0%（相对平均值），可直接与路线 B 的 $\sqrt2$ 倍以内对照；差别在于路线 B 的聚合保持与 GeoSOT 标准网格边界重合，细节差异待实验比较。

预期结论是两者按用途分工：路线 B 用于统计、索引与剖分图构图，路线 A 用于需要严格等面积的科学计算与和 HEALPix 的对照。

### 3.4 椭球与高程

在 WGS84 椭球上以等积纬度替代地理纬度即可保持闭式交叠公式；高度维沿用 GeoSOT-3D 剖分，等面积只针对水平方向。需评估球面近似与椭球计算在各层级的面积差异，给出何时可以用球面近似的判据。

## 4. 实验设计

| 项目 | 内容 |
| --- | --- |
| 验证网格 | GeoSOT 为主，另选 Geohash 与 WorldCRS84Quad 验证通用性 |
| 几何指标 | 面积变异系数与极差比；形状比；与 HEALPix、ISEA 同尺寸层级的对比 [^5] |
| 守恒检验 | 在 ERA5 等全球场上做 GeoSOT 与派生视图之间的往返映射，统计质量与能量守恒误差 |
| 统计偏差 | 全球与纬度带均值在不加权 GeoSOT、加权 GeoSOT、派生视图三种方式下的差异 |
| 下游任务 | 以派生视图为节点的剖分图（2-4）与原始 GeoSOT 剖分图的预报精度与效率；不确定性聚合的跨层级一致性（板块三） |
| 计算开销 | 权重表生成时间与大小、映射吞吐 |

## 5. 预期成果

1. 两种等面积派生视图的定义、编码方式与层级规则。
2. 派生视图与 GeoSOT 网格之间闭式精确的对应关系与守恒重映射方法。
3. 面向统计、剖分图与模式输出的使用指南：何种计算应在何种视图上进行。
4. 期刊论文一篇，建议投 IJGIS 或 Geoscientific Model Development；派生视图规则可作为 1-5 标准修订建议中的资料性附录。
